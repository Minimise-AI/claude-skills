# Claude skills from Minimise

Free Claude Code skills for marketing agencies, from the videos we post.

## Skills

| Skill | What it does |
|---|---|
| [drive-structure](drive-structure/) | Sets up one clear Google Drive structure for every client's assets, so AI can find the right hooks, bodies, B-roll and images when it makes an ad. |

## How to install a skill

1. Download this repo: click the green **Code** button, then **Download ZIP**, and unzip it.
2. Copy the skill's folder (for example `drive-structure`) into the `.claude/skills` folder
   of the workspace you open Claude Code in. Make the `.claude/skills` folder if it isn't
   there yet.
3. Open Claude Code in that workspace and ask for it, for example "set up my Drive
   structure".

Each skill says what it needs (tools, apps, keys) at the top of its `SKILL.md`.
